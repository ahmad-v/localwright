# Changelog

## 0.1.0 (unreleased)

- Add bounded monochrome line and scatter style helpers with distinct markers and dash encodings for print use.
- Prepare separately installable core and UI crates with package-specific documentation, license texts and a runnable workbench example.
- Include the shared operation contracts, cooperative jobs, bounded file helpers, JSON settings, vector scatter export, and native workbench with twenty themes and UI scaling.
- Use Rust 1.88 for the first registry release.

## 0.1.0-alpha.1 (unreleased)

- Added source for JSON settings parse/save-new.
- Added source for Single background job and cooperative cancellation.
- Added source for 20 client-area color presets.
- Added source for Monochrome vector scatter SVG.
- Added source for Independent character-count GUI example.

This alpha snapshot preceded crates.io publication.
